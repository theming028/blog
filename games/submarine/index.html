🎯 基本操作

  • 手机端：按住屏幕并左右拖动，战舰会跟着手指走；轻一下屏幕 = 投弹（拖动过程中不会误投）
  • 💣 按钮 = 投弹，W 按钮 = 切换武器，⏸ = 暂停
  • ← → 或 A/D 移动战舰（长按可加速）
  • 空格 / J 投掷当前武器
  • 数字键 1-3 切换已解锁武器
  • ESC 暂停，Enter 开始游戏

🚀 武器系统

  • W1 深水炸弹：基础武器，升级后爆炸范围更大（LV1-3）
  • W2 追踪鱼雷：下潜后自动索敌，命中必杀
  • W3 深海火箭：直线俯冲，可穿透海沟，伤害极高
  • 拾取 武器箱 解锁/升级武器

💰 积分与连击

  • 普通潜艇 10分 · 精英潜艇 25分 · 猎手潜艇 40分 · 布雷艇 30分
  • 金核Boss 500分，多阶段血量，会发射扇形鱼雷
  • 连续命中形成 COMBO，得分倍率最高 ×3

🎁 道具

  • 🧰 武器箱：解锁/升级武器
  • 🛡 护盾：抵挡一次鱼雷
  • ❤️ 医疗箱：恢复 1 条生命
  • ⭐ 双倍分数：持续 12 秒
  • ⏱ 时间冻结：敌舰静止 4 秒

🌊 海域天气

  • 每片海域天气不同：晴朗 / 黄昏 / 暴风雨 / 深夜闪电 / 火山海域
  • 暴风雨海浪汹涌，闪电照亮深海；火山海域有落石危险

⚠️ 敌方单位

  • 普通潜艇：深灰色，速度慢
  • 精英潜艇：暗灰色，速度快，血量高
  • 猎手潜艇：会主动追踪你的位置并发射制导鱼雷
  • 布雷艇：缓慢移动并布放漂浮水雷
  • 金核Boss：击毁70%潜艇后登场，击沉后过关
