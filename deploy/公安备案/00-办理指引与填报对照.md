# 公安联网备案 · 办理指引与填报对照

> 适用对象：`shaoym.me`（个人非经营性博客，含访客评论/点赞等交互功能）
> 办理入口：全国互联网安全管理服务平台 <https://beian.mps.gov.cn>
> 本文件由代码与服务器实测生成，制度类描述均对应本站**真实实现**，不是通用模板。

## 一、办理时序（这一步最容易做错）

```
① ICP 备案下号  →  ② 打开站点并切 HTTPS、页脚挂 ICP 备案号  →  ③ 提交公安备案  →  ④ 下号后 30 日内挂公安备案号
```

**关键冲突**：ICP 备案期间要求网站处于关闭状态（本站已按要求用 Nginx 对非本站域名一律 444，按 IP 也不可访问）；
而公安备案的阿里云官方指引明确写着——

> 新办网站审核期间，您需要确保审核人员能随时访问网站，否则审核不通过。

所以**不能在站点关闭的状态下提交公安备案**。正确顺序是：ICP 下号 → 撤掉关闭措施、切 HTTPS、页脚挂 ICP 备案号 →
确认公网能打开 → 再提交公安备案。撤销关闭措施的操作见《上线手册.md》，或让我执行。

另两条时限：ICP 通过后 **30 日内**提交公安备案；公安下号后 **30 日内**完成备案号悬挂。

## 二、平台注册与实人认证

1. 访问 `beian.mps.gov.cn` → 注册账号（个人主体用身份证）。
2. 按提示下载「公安一网通办」APP，扫码完成**实人认证**。
3. 【业务办理】→【新增主体】→ 主体性质选**个人** → 上传证件 + 完成负责人认证（文件认证或国家网络身份认证 APP 二选一）。
4. 【业务办理】→【网站业务】→【新办网站申请】，共 4 步：开办主体 → 网站基本信息 → 网站负责人 → 阅读《互联网信息服务单位网络安全责任告知书》并提交。
5. 属地公安机关网安部门核验，**30 个自然日内**出结果；期间可能来电，保持手机畅通。

> 注意：公安机关不单独审核主体，必须同时提交网站申请，主体才进入完整流程。

## 五、必须提醒你的两个风险点

**1）个人备案 + 开放评论，各地执行口径不一致。**
本站确实对未登录访客开放评论与点赞，属于「交互式服务」。阿里云指引要求如实勾选；
但同时有公开资料称个人性质网站不宜设置论坛/留言社区类栏目（论坛属前置审批项目）。
实际执行差异较大，建议：

- 提交前**先电话咨询属地网安部门**（成都），确认个人博客开放评论是否可行；
- 若被告知不行，可选：① 审核期间临时关闭评论（后台可关，审核通过后再开，但需按「新增功能」做变更报备）；
  ② 改为仅登录/仅自己可评论；③ 以单位主体备案。
- 阿里云指引也提到：不确定时可先选「否」，被驳回后再改选重新提交——但**信息不实本身是驳回与处罚事由**，
  我不建议用这条路规避，宁可先问清楚。

**2）前台目前没有举报入口。**
后台有完整的审核能力（自动检测 + 待审队列 + 屏蔽/通过），但访客侧没有「举报此评论」的按钮。
交互式服务备案通常会被要求提供**畅通的举报渠道**。这是一处真实缺口，建议补齐后再提交
（实现很小：评论上加举报入口 → 写入后台待审队列并通知你）。要我做的话说一声。
