## C. 需要你拍板的三个实质问题

**1）个人备案 + 开放评论，能不能过？**
本站对未登录访客开放评论与点赞，属「交互式服务」。阿里云指引要求如实勾选；
但有公开资料称个人性质网站不宜设留言/论坛类栏目（论坛属前置审批项目）。各地执行差异大。

> 建议：**提交前先电话咨询成都属地网安**，确认个人博客开放评论是否可行。
> 若被告知不行，可选：① 审核期临时关闭评论、下号后再开（届时须按「新增交互功能」做变更报备）；
> ② 改为仅登录可评论；③ 用单位主体备案。
> 我不建议按某些教程说的「先选否、驳回再改」——信息不实本身就是驳回与处罚事由。

**2）网络日志留存不足六个月，要不要现在整改？**
实测：Nginx 访问日志 `daily + rotate 10` ≈ **10 天**，应用内访问行为日志 **90 天**，
而《网络安全法》第二十一条要求**不少于六个月**。这一项在服务器上一查便知，材料里没法含糊。

> 两处改动都很小：logrotate `rotate 10 → 200`；应用留存常量 `90 → 180` 天。
> 日志压缩后体积很小，以当前访问量不会造成磁盘压力（系统盘剩 23 GB）。
> **要我现在就改吗？** 改完我再把 `04` 里的数字改成整改后的实际值。

**3）站内举报入口缺失，补不补？**
后台审核能力完整（自动检测 + 待审队列 + 屏蔽/通过 + 状态统计），但**前台没有「举报此评论」按钮**，
目前只有邮箱单一渠道。交互式服务备案通常要求有畅通举报渠道。

> 实现很小：评论上加举报入口 → 写入后台待审队列并标记来源。
> **要我现在就补吗？** 若暂不补，我已把 `03` 文档中「站内入口」一行标注为待办，
> 提交时按实际情况取舍，不会把未上线的功能写成已有能力。

## D. 时序提醒（最容易做错的地方）

```
ICP 下号 → 撤掉「备案期关闭」措施 + 切 HTTPS + 页脚挂 ICP 备案号
        → 确认公网可访问 → 再提交公安备案
```

公安备案明确要求**审核期间审核人员能随时访问网站**，否则不通过；
而 ICP 备案期间网站必须处于关闭状态。本站目前是按 ICP 要求关闭的（非本站域名一律 444），
**不要在这个状态下提交公安备案**。
