# 违法不良信息防范处置与举报制度

**域名**：shaoym.me　**适用范围**：访客提交的评论内容、作者发布内容、友情链接

## 一、信息审核机制

本站对用户提交内容实行「**自动检测拦截 + 人工复核**」双重机制，两者均已上线运行。

### 1. 自动检测（发布时即时执行）

评论提交时由服务端规则引擎逐条判定，命中任一规则即**不直接公开**，转为「待审」状态并记录命中原因：

| 检测类别 | 具体规则 | 命中后判定原因 |
| --- | --- | --- |
| 外部链接 | 含 `http(s)://`、`www.` 或常见域名后缀拼接形式的链接 | 包含外部链接 |
| 违法违规内容 | 管制器具、毒品、迷药等 **36 项**违法关键词库 | 疑似违规/违法内容 |
| 广告营销 | 加微信/QQ、微商、代购、返利等 **51 项**广告关键词库 | 疑似广告/营销 |
| 手机号引流 | 11 位手机号形态（前后断言避免长数字误命中） | 疑似手机号引流 |
| 联系方式引流 | 「微信/vx/扣扣/电话/联系方式」等 + 账号形态的组合匹配 | 疑似联系方式引流 |
| QQ 号引流 | 「qq/扣扣/企鹅」+ 5–12 位数字 | 疑似联系方式引流 |
| 灌水刷屏 | 去除空白后长度 ≥15 且不重复字符种类 ≤3 的重复内容 | 疑似刷屏 |

关键词库与规则随监管要求与垃圾信息形态变化定期更新。

### 2. 人工复核（后台审核队列）

- 评论内容设三种状态：**公开（visible）/ 待审（pending）/ 屏蔽（hidden）**；
- 命中自动检测的内容进入「待审」队列，由网站负责人在管理后台逐条判定为「通过」或「屏蔽」；
- 后台提供各状态数量统计（总数 / 公开 / 待审 / 屏蔽），确保待审内容不被遗漏；
- 未命中规则的内容默认可见（先发后审），命中规则的内容一律先审后发；
- 作者自身发布的内容由作者自行负责，同样受本制度约束，可随时删除或撤回。

## 二、禁止发布的信息范围

依照《网络安全法》《互联网信息服务管理办法》第十五条等规定，本站禁止制作、复制、发布、传播下列信息：
反对宪法确定的基本原则的；危害国家安全、泄露国家秘密、颠覆国家政权、破坏国家统一的；
损害国家荣誉和利益的；煽动民族仇恨、民族歧视，破坏民族团结的；破坏国家宗教政策，宣扬邪教和封建迷信的；
散布谣言，扰乱社会秩序，破坏社会稳定的；散布淫秽、色情、赌博、暴力、凶杀、恐怖或者教唆犯罪的；
侮辱或者诽谤他人，侵害他人合法权益的；含有法律、行政法规禁止的其他内容的。

## 三、处置流程与时限

1. **发现途径**：自动检测命中、网站负责人日常巡查、用户或权利人举报、公安机关或主管部门通知。
2. **先期处置**：对涉嫌违法不良信息，**立即停止传输**——在后台将其状态置为「屏蔽」，
   内容即刻从公开页面移除。
3. **处置时限**：自行发现或接到举报后 **24 小时内**完成初步处置（下架/屏蔽）；
   属于公安机关或主管部门通知的，按其要求时限办理，一般不超过 24 小时。
4. **记录保存**：保留该内容原文、提交者来源 IP、提交时间、处置时间与处置理由，
   作为日志留存的一部分，保存期限不少于 6 个月。
5. **报告**：对违法情节严重、涉及危害国家安全或公共安全的信息，在处置的同时
   保存有关记录并向属地公安机关网安部门报告。
6. **申诉与更正**：被处置内容的提交人如有异议，可通过举报渠道邮箱联系负责人复核；
   确认误判的予以恢复并记录原因。

## 五、友情链接管理

页脚友情链接仅由网站负责人人工添加，添加前审核目标站点内容合法性；
链接统一带 `rel="noopener nofollow"`，不为其内容背书；
发现被指向站点存在违法信息或域名易主、失效的，立即移除并记录。

## 六、责任与更新

本制度由网站负责人负责执行与解释，随法律法规和垃圾信息形态变化及时修订；
关键词库与检测规则更新后，同步修订本制度对应条款。
